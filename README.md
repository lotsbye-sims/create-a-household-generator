# Sims Move-In Card

A random generator for The Sims 4. It rolls a household with a short backstory, traits and an aspiration for every resident, and the lot they move into. Each part can be rerolled on its own.

The whole tool is a single `index.html` file, with nothing to install and no server. Open it in a browser or turn on GitHub Pages.

All the data (names, surnames, traits, worlds, lot traits) sits in plain lists at the top of the script in `index.html`, so it's easy to add more.

Unofficial fan tool, not affiliated with or endorsed by EA.
